# Rejaka Abimanyu Susanto — Portfolio

My personal portfolio site — blog, projects, work experience, and achievements, all built as a fast, minimal, static site.

🔗 **Live:** [rejaka.id](https://rejaka.id)

Built with Astro, Tailwind, and TypeScript. No extra frameworks.

Based on [Astro Sphere](https://github.com/markhorn-dev/astro-sphere) by [markhorn-dev](https://github.com/markhorn-dev), customized with:
- Achievements page with year-grouped cards and a click-to-enlarge image modal
- Projects with flexible multi-link support (frontend/backend repos, live demos, downloads, etc.)
- Random project shuffle on the homepage and projects index
- Year-based grouping instead of date-based sorting (blog, achievements, projects)
- Custom favicon, content, and styling

## 💻 Commands

All commands run from the root of the project, in a terminal. Replace `npm` with your package manager of choice (`pnpm`, `yarn`, `bun`, etc).

| Command                   | Action                                            |
| :------------------------ | :------------------------------------------------ |
| `npm install`              | Installs dependencies                              |
| `npm run dev`               | Starts local dev server at `localhost:4321`        |
| `npm run dev:network`       | Starts local dev server on local network           |
| `npm run sync`               | Generates TypeScript types for all Astro modules   |
| `npm run build`              | Build production site to `./dist/`                 |
| `npm run preview`            | Preview build locally, before deploying             |
| `npm run preview:network`    | Preview build on local network                       |
| `npm run astro ...`           | Run CLI commands like `astro add`, `astro check`     |
| `npm run astro -- --help`     | Get help using the Astro CLI                          |
| `npm run lint`                | Run ESLint                                            |
| `npm run lint:fix`            | Auto-fix ESLint issues                                |
